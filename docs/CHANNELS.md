# WebSocket Channel Coverage

Generated from [internal/channels.yaml](../internal/channels.yaml) by `go run ./internal/gendocs` — do not edit this file by hand, edit the manifest and regenerate. REST coverage is in [ENDPOINTS.md](ENDPOINTS.md).

Every row is a typed subscription method on a streaming `Session`: the payload is a Go struct, so applications never parse JSON. The manifest tests (`manifest_test.go`) fail the build if a row does not resolve to a real method, if its test does not exist, or if a `Subscribe…` method exists without a row. See [STREAMING.md](STREAMING.md) for the connection lifecycle, back-pressure and order-book semantics.
